# Excelでの使い方

画面で動きを見たあと、同じコードを実際にExcelで動かしてみる。方法は2つ。

## 方法1：画面のコードをコピペする（おすすめ）

1. アプリの画面で試したいアルゴリズムを選ぶ。
2. 「コードをコピー」ボタンを押す。
3. Excelを開き、`Alt + F11` で VBE（VBAエディタ）を開く。
4. メニュー「挿入」→「標準モジュール」。
5. できた白い画面（コードペイン）に貼り付ける（`Ctrl + V`）。
6. A列（1行目から、空欄なしで）に数値を入れておく。
7. 貼り付けたコードの中にカーソルを置いて `F5`。
8. B列に並べ替えた結果が出る。

この方法は、コピー元が画面表示（Unicode）のまま貼り付けられるので、日本語コメントが文字化けしない。
**基本はこちらを使う。**

## 方法2：`SortDemo.bas` を丸ごとインポートする

5種類のアルゴリズムを1つのモジュールにまとめたものが `excel/SortDemo.bas` にある。
一つ一つコピペするのが面倒なときはこちら。

1. Excelを開き、`Alt + F11` で VBE を開く。
2. メニュー「ファイル」→「ファイルのインポート」。
3. `SortDemo.bas` を選ぶ。
4. 左側のプロジェクトエクスプローラーに「SortDemo」モジュールが追加される。
5. A列（1行目から、空欄なしで）に数値を入れておく。
6. 実行したいSub（`BubbleSort` など）にカーソルを置いて `F5`。
   実行するSubを選ぶ画面が出たら、目的のものを選んで「実行」。
7. B列に並べ替えた結果が出る。

`SortDemo.bas` に入っているSubの名前：

| Sub名 | アルゴリズム |
|---|---|
| `BubbleSort` | バブルソート |
| `SelectionSort` | 選択ソート |
| `InsertionSort` | 挿入ソート |
| `ShellSort` | シェルソート |
| `QuickSortCaller` | クイックソート（実行はこちらを選ぶ） |

`QuickSort` という名前のSubも中にあるが、これは `QuickSortCaller` から自動的に呼ばれる
再帰処理の本体なので、直接実行するものではない。

`SortDemo.bas` はA列の件数を自動で数える（`Cells(Rows.Count, 1).End(xlUp).Row`）ので、
本数を書き換える必要はない。画面のコピペ版は本数が固定（棒の本数）だが、動きは同じ。

## うまくいかないとき

- **「型が一致しません」と出る**：A列に数値以外（空欄・文字列）が混ざっていないか確認する。
- **マクロが無効と警告される**：`.bas` を一度テキストエディタで開いて内容を確認してから、
  信頼できる場合のみインポートする。学校のPCではマクロの有効化そのものが制限されている
  ことがあるので、その場合は方法1（コピペしてその場でF5）で十分。
- **日本語コメントが文字化けする**：`.bas` をテキストエディタで直接開くと、エディタの既定エンコード
  （多くはUTF-8）とVBAのファイル形式（ANSI／日本語環境ではCP932）が食い違って化けて見えることがある。
  Excelの「ファイルのインポート」経由で読めば正しく表示される。

## 開発者向け：`SortDemo.bas` の作り方

`excel/SortDemo.bas` は手で編集しない。`js/algorithms/*.js` の `vba()` が唯一の正なので、
アルゴリズムを追加・変更したら次の2手順で作り直す。

```bash
node tools/build-bas.js > tools/SortDemo.utf8.txt
python tools/to-cp932.py tools/SortDemo.utf8.txt excel/SortDemo.bas
```

1本目（Node）が `js/algorithms/*.js` の `vba()` を評価してUTF-8のVBAソースを組み立て、
2本目（Python）がそれを CP932 に変換する。CP932 に変換できない文字（em dash `—` など）が
混ざっていたら、2本目が位置を示して失敗するので、そこで気づける。
